Every turn is a Git commit

Agent orchestration framework with git-backed storage. Inspectable, rewindable, forkable. Every decision tracked. Every state recoverable.

Get Started API Reference 
from gitlord import Session, SessionConfig

config = SessionConfig(log_repo_path="log")
session = Session.create("my-agent", config)
session.append_user_turn("What's the weather in London?")

# Every turn is a git commit — inspectable, rewindable
for turn in session.get_turns():
    print(f"  [{turn.role}] {turn.content[:80]}")

Why GitLord

[git]

Git-Backed Storage

Every agent turn is a real git commit. Full history, branching, and inspection using standard git tooling. No custom databases.

[rewind]

Rewind & Fork

Jump back to any point in your agent's history. Fork a new branch from any turn. Original history is never mutated.

[sub]

Subagent Orchestration

Spawn subagents on isolated branches. Parallel execution with automatic result integration via commit trailers.

[mcp]

MCP Tool Integration

Connect any MCP server for tools — filesystem, browser, search, custom. Auto-discovery, crash recovery, tool namespacing.

[ctx]

Smart Context Assembly

Incremental context building with dedup, summarization, and token budgets. Only processes new turns since last assembly.

[rag]

Vector Index & RAG

Built-in ChromaDB integration. Index turns and external documents. Semantic search across your entire agent history.

Architecture

Plumbing-first design. No working tree for log writes. Concurrent subagents without lock contention.

┌─────────────────────────────────────────────────────────────────────┐ │ refs/agents/<session-id> │ │ ├── turns/00000000000000000000-system.json │ │ ├── turns/00000000000000000001-user.json │ │ ├── turns/00000000000000000002-assistant.json │ │ └── ... │ │ │ │ refs/agents/sub/<session-id>/<subagent-id> │ │ ├── turns/00000000000000000000-system.json │ │ └── turns/00000000000000000001-tool_result.json │ └─────────────────────────────────────────────────────────────────────┘ Session.create() ──→ create_orphan_branch ──→ system turn commit │ append_turn() ──→ hash-object ──→ mktree ──→ commit-tree ──→ update-ref (CAS) │ rewind() ──→ verify commit on branch ──→ new branch at target SHA │ SubagentManager.spawn() ──→ branch at parent tip ──→ subagent turns │ SubagentManager.complete() ──→ enqueue in parent queue ──→ Subagent-Result trailer

Install

Python 3.11+. Core runs with just pydantic. Add optional extras as needed.

pip install gitlord[all]
Core: pip install gitlord  |  MCP: pip install gitlord[mcp]  |  LLM: pip install gitlord[litellm]  |  RAG: pip install gitlord[chromadb]
